# Clear databases Implementation Plan

Goal: очистить записи без удаления документов и без автоматического восстановления.
Architecture: команды App очищают выбранные списки и отключают источники в settings; поколения сканирования отбрасывают устаревшие результаты. Knowledge сопоставляет один путь и вид акта при обновлении.
Tech Stack: Python, Tkinter, unittest.
