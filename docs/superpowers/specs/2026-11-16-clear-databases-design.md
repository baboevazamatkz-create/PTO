# Очистка баз
Согласовано: удалять записи программы, сохраняя исходные документы. В меню «База» доступны очистка актов, сертификатов и обеих баз с подтверждением. Источники выбранной базы отключаются, чтобы повторный запуск не вернул записи; повторное подключение доступно штатными командами. Проект помещений, материалы, подписанты и форма сохраняются. Результаты фонового сканирования, запущенного до очистки, отбрасываются.
Исправить подтверждённый сценарий дублей: повторный импорт того же пути обновляет запись даже при изменении текста. Разные виды актов сохраняются отдельно. Не объединять произвольно разные файлы по похожему тексту.
